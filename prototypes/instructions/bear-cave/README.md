# Bear Cave

Tyler Myrans

[View this project online](https://imbear001.github.io/CART253/prototypes/instructions/bear-cave/)

## Description

A static night scene of a bear peeking out of its cave, built by layering basic p5 shapes: a custom rock shape, an arc for the cave mouth, and ellipses for the bear.

## Attribution

- This project uses [p5.js](https://p5js.org).
- Splitting the drawing into named functions is based on Pippin Barr's "Cat" example.
