# Additive Light

Tyler Myrans

[View this project online](https://imbear001.github.io/CART253/prototypes/instructions/additive-light/)

## Description

An abstract piece that mixes red, green, and blue light using `colorMode(HSB)` and `blendMode(ADD)`, so overlapping circles add up to yellow, cyan, magenta, and white, framed by a ring of coloured arcs.
