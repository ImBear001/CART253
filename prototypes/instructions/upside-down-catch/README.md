# Upside Down Catch

Tyler Myrans

[View this project online](https://imbear001.github.io/CART253/prototypes/instructions/upside-down-catch/)

## Description

The food chain is upside down: a giant salmon dives out of a cloud to catch the bear from Bear Cave, who has turned into a bear-fish swimming in the river. Built with triangles (the salmon's head, teeth, and the bear-fish's tail), arcs for scales, and see-through water using the fourth number in `fill()`.
